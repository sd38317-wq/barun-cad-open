# 계정 및 업데이트 통합 창 v2
네 앱 담당자는 work-order.json부터 읽으세요. 모든 주요 지시·디자인·자가 복구·통합 인증 요구는 JSON입니다.
이 패키지는 **작업 지시/계약/참고 시안**이며 앱에 아직 적용되지 않았습니다.
이전 login-handoff-v1 작은 로그인 카드와 파일 연결 규격은 사용하지 마세요.

공통 JSON + 공통 렌더러 + 동일 폰트/에셋 버전을 사용해야 같은 화면이 됩니다.
앱별 변경은 이름/아이콘/앱 ID/실행 버전 바인딩만 허용합니다. 공식 아이콘은 P0에서 확인합니다.
reference.png는 새 통합 창 시안입니다. 제품 버전/모델/계정 데이터는 실제 런타임으로 바인딩하세요.

검증: node validate.mjs (Node 내장 모듈만 사용).
이 검사는 계약 구조와 일관성만 확인하며 제품 동작이나 JSON Schema 전체 구현을 검증하지 않습니다.
실제 앱·SSO·자가 복구 테스트는 work-order.json에 따라 별도 수행합니다.
