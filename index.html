명령 별칭 · 단축키

별칭은 입력 후 Enter로 실행합니다. 기본값: COPY = C, CIRCLE = CI. 정식 명령 이름은 항상 사용할 수 있습니다.

단축키 예: Ctrl+Shift+C, Alt+R. 단일 문자는 별칭에서 지정하세요. 좌표·문자·설정 입력 중에는 단축키가 개입하지 않습니다.

명령 기능 별칭 + Enter 즉시 단축키

명령 목록 · 사용법

명령을 입력하고 Enter → 화면 아래 안내에 따라 선택/좌표/값 입력. Esc로 취소합니다. 명령 중에도 정식 명령/별칭으로 바꿀 수 있지만, 문자 내용·블록 이름 입력 단계에서는 글자를 그대로 입력합니다.
